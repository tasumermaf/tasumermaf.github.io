Geometry

The shape of the cell

Computation defaults to the cubic grid, where each node has six neighbours. The face-centred cubic lattice gives each node twelve. At matched node count its average paths are 30% shorter and its algebraic connectivity 2.3 to 2.5 times higher, at about twice the edges.

The same program reads what fine-tuned adapters have learned from their weights alone.

State

Exact return

A system can show the same reading twice while the state behind it has changed. Crossroads State keeps the whole field, the order in which it is read and its reference address together, so that a return can be checked exactly and not inferred from appearances.

Foundations

Habits of the machine

Calculemicha is a book in sixteen stations. It walks from Leibniz's dream of settling arguments by calculation to the question of what makes a physical system a computer, and at each station asks which parts of computation are necessary and which are habits.

The bookAudiobook

On the lattice result, the scope matters. Our own pre-registered control showed that a random rewiring of the same edges beats the lattice on connectivity, but only with wires that grow without bound. The claim that stands is narrower: among arrangements that can be built with local wiring, the twelve-neighbour lattice dominates the cube. Where a task has no spatial metric, our null results say the geometry does not help.

Crossroads

Pattern, persistence, transit, return

Imagine a board of eighty-one numbers and a small window that shows only some of them. Move the window and what you see changes while the board does not. Change a number outside the window and the board changes while what you see does not.

Crossroads gives these things separate names: the field, the reader and the reference. Together they are the state, and the record of what was done to it is the journal. A reading can agree, the full state can agree, and the route can agree. Each needs its own evidence, and the instrument tests each one.

Method

How a result earns its place

The method is the product. A finding that cannot be checked by someone else is treated as a draft.

  1. Register first.Hypotheses, pass criteria and analysis choices are fixed in a dated record before the data exists. The registered text is never revised. A deviation is a dated amendment beside it.
  2. Refuse partial data.Analysis tools will not run on an incomplete experiment. The interlock is in the code, so no early look can steer a result.
  3. Run the controls first.Null models and positive controls are calibrated before any trained arm. A test that cannot detect a planted effect is not allowed to report an absent one.
  4. Separate maker and referee.Designs are reviewed by an independent referee with no shared context, and its rulings are recorded word for word. Headline numbers are derived again from the raw items.
  5. Audit adversarially.Each paper passes through repeated hostile review before release. The ladder for The Gauge Is the Obstacle confirmed 117 findings and fixed 92, and every disposition is on record.
  6. Correct in the open.Retractions, errata and failed predictions are published beside the claims they change. Our own control narrowed our best-known lattice claim, and the narrower claim is the one we state.

Beyond the published work we develop training methods for models that must carry a complete state through a sequence of changes and return exactly, with every claim checked by independent replay. These methods are unpublished and are discussed only under a written agreement.
